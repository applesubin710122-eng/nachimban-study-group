# 나침반 스터디 그룹 v5

버튼형 관리자/회원 화면 + π 포인트 경제 + 데일리/위클리 미션 + 사진 인증 + 운영진 승인/자동 보상 + DAY OFF + 공개 배포용 설정.

## 1. 로컬 실행
```bash
npm install
npm start
```
브라우저에서 `http://localhost:3000`

대표 초기 계정: `admin` / `123456`

## 2. 핵심 기능
- 대표/부대표/멘토/멘티 역할
- 대표가 부대표 권한을 버튼으로 선택
- 회원 생성 및 비밀번호 초기화
- 데일리/위클리 미션 생성
- 미션별 π 보상 설정
- 시작/종료일 설정
- 사진 또는 메모 인증 제출
- 운영진이 인증 승인/반려
- 승인 즉시 π 자동 지급 및 거래 내역 기록
- π로 DAY OFF 구매
- 운영진의 π 직접 지급/차감
- 수강 신청 기간 및 신청자 승인
- 익명 상담
- 게시판

## 3. 실제 인터넷에 공개하기
GitHub에 이 폴더의 파일을 올린 뒤 Render에서 `New > Web Service`로 저장소를 연결합니다.

Build Command: `npm install`
Start Command: `npm start`

이 프로젝트에는 `render.yaml`이 포함되어 있습니다. Render에서 이 설정을 적용하면 `/var/data` 영구 디스크를 사용해 SQLite DB와 업로드 사진을 보존하도록 구성됩니다.

### Render 설정에서 확인할 환경변수
- `NODE_ENV=production`
- `SESSION_SECRET`은 긴 랜덤 문자열
- `DB_PATH=/var/data/data.sqlite`
- `UPLOAD_DIR=/var/data/uploads`

배포가 완료되면 Render가 제공하는 `onrender.com` 주소로 다른 사람도 접속할 수 있습니다.
